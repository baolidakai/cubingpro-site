6x6 Last Two Centers (L2C)

六阶最后两个中心。Reduction / Yau 做到只剩两个中心没拼好时，就是 L2C。

摆法：把最后两个中心放到 U（顶）和 F（前），另外四个中心已经拼好、整个过程不能动它们。

图和 Yau 页里 5x5 L2E 是同一套画法：只画要看的面，不画整个魔方。

怎么看图

左图 = U 中心 4x4，右图 = F 中心 4x4。白色 = 属于 U 的块，绿色 = 属于 F 的块。

U 的底边就是 F 的顶边 —— 两图贴着的那条边是同一个交界。

上面是拼好的样子：左全白，右全绿。

中心块分三种

6x6 一个面的中心是 4x4 = 16 块，分三类，互不串门：

  • C 角中心 ×4：四个角。
  • E 边中心 ×8：四条边上、每边 2 块。
  • I 内中心 ×4：中间 2x2。

所以 L2C 不是“16 块乱了”，而是三类各自在 U、F 之间换位置。先认清是哪一类错了，再动手。

核心思想：只用 commutator

宽转动会整列搬中心块，U 只转顶层。把两者拼成 commutator：

[宽转动, U] = 宽转动 + U + 宽转动逆 + U逆

好处是：只动 U 和 F 的中心，另外四个中心完全不动。下面三个触发器都是这个结构，效果经 6x6 模拟验证过。

记号：2R = 从右数 2 层一起转，3R = 从右数 3 层一起转，U = 只转顶层外层。

三个触发器：错块在右侧交界时直接用

下面每张图都是“错块已经转到右侧交界”的样子。你的实战 case 只要把错块转到这个位置，就能直接套公式。

Case 1：最外列 3 块互换

U 右列下 3 块是绿，F 右列上 3 块是白。

解法：U 2R U' 2R'

只动最外列，不动内侧 2x2。

Case 2：右下 / 右上 2x2 块互换

U 右下 2x2 是绿，F 右上 2x2 是白。

解法：U 3R U' 3R'

一次搬 2x2 块，是 Case 1 的“加宽版”。

Case 3：内侧第 3 列 3 块互换

U 第 3 列（从左数第 3 列）有 3 块是绿，F 第 3 列有 3 块是白，最外列全对。

解法：U 2R' 3R U' 3R' 2R

其中 2R' 3R 就是只转中间那一层 slice，只动第 3 列，不动最外列。

实战流程：setup → 触发器 → 还原 setup

  1. 看 U、F 交界，找出错块在哪一列、在哪一类（C / E / I）。
  2. Setup：只转 U 或 F（U / U' / U2 / F / F'），把错块转到上面三个图里对应的右侧位置。不要转整个魔方。
  3. 用对应的触发器。
  4. 还原 setup：setup 是 U，就做 U' 还原；是 U2，就再做 U2。
  5. 重复，直到 U、F 全对。

顺序建议：先内后外。Case 3 只动第 3 列，Case 1 只动最外列，两者互不干扰；Case 2 一次动两列，留在最后当捷径。

常见坑

  • 忘了还原 setup —— 触发器本身是对的，setup 没还原会把别的列带偏。
  • 中途转体（y / x）—— U、F 换了，触发器的“右侧”就不是原来的右侧了。固定握法，转 U / F 就够了。
  • 用 U 一个人“转回去”—— U 会把 U 中心内部旋转，中心看起来对了、实际位置错了，要用触发器而不是单 U。

和 5x5 L2E 的关系

Yau 页的 5x5 L2E 是“最后两条棱”，这里是“最后两个中心”。画法一样、思路一样：都是找交界、做 commutator、保住已拼好的部分。学会 L2C，6x6 的中心就不用背一堆 case，三个触发器 + setup 就够了。
