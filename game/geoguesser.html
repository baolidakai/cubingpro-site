GeoGuesser 攻略

社区实战技巧的图文总结：国旗、车牌、路牌、标线、半球、语言。内容以中文为主，关键术语中英对照；国旗图可点开看大图（图片由 flagcdn.com 提供）。配套练习：国旗 Trainer。

国旗速认

三步口诀：先看条纹方向（横 / 竖 / 十字），再看旗杆侧颜色，最后看国徽、星月等小图案。实战提醒：GeoGuessr 里国旗本体很少直接出现，更多是国旗配色刷在电线杆、路牌、建筑上（比如印尼电线杆常刷红白、加纳街头常见红黄绿配色）——看到配色先反应国家，再验证。

vs

区分：蓝黄红竖三条几乎完全相同，乍得的蓝更深（靛蓝）、旗面略窄长。街景里基本无法只靠旗区分，必须结合车牌、语言。

vs

区分：都是红上白下横两条，摩纳哥旗更窄长、红更深。实战更可靠的是地理逻辑：摩纳哥是袖珍城邦，看到密集城区、港口游艇直接锁摩纳哥。

vs

区分：绿白橙竖三条，看旗杆侧颜色——绿在杆侧是爱尔兰，橙在杆侧是科特迪瓦。

vs

区分：红白蓝横三条，卢森堡的蓝明显更浅、旗面更长。两国都用黄色后车牌，可辅证。

vs

区分：都有米字旗 + 南十字星。澳大利亚是白色七角星（左下还有一颗大七角星），新西兰是四颗红色白边五角星、旗面看起来更"空"。

vs

区分：颜色上下正好颠倒——白上红下是波兰，红上白下是印尼。记住"波兰白在上"。

vs

区分：白蓝红横三条 + 国徽。斯洛文尼亚国徽在旗杆侧上方，斯洛伐克国徽偏中且有双十字——社区实战里最常认错的一对。

vs

区分：都是十字旗，挪威是红底蓝十字（白边），冰岛是蓝底红十字（白边）——底色和十字颜色正好互换。

vs

区分：都是黑黄红三色，比利时竖条、德国横条——先看条纹方向就能分。

vs

区分：都是竖三条，看旗杆侧颜色——蓝在杆侧是法国，绿在杆侧是意大利。

vs

区分：红白绿横三条，红色在上是匈牙利，白色在上是保加利亚。

vs

区分：都是条纹 + 左上蓝底。马来西亚蓝底上是黄色新月和星，美国是 50 颗小星。

国家区分：车牌 / 标线 / 杆桩 / 街景车

车牌：看形状和颜色，不看字母

  • 车牌左侧有蓝色竖条 = 欧盟或周边欧洲国家；黄色后车牌 = 荷兰、卢森堡、英国。长窄牌偏欧洲、方正牌偏北美，模糊的车牌边缘也够锁定大洲。
  • 哥伦比亚是黄色车牌，且停车牌写 "PARE"（而非 STOP）——黄牌 + PARE 双保险。（低置信度：来源为南美攻略视频的 AI 摘要）
  • 阿根廷车牌中央有一个黑点，看到黑点先考虑阿根廷。
  • 葡萄牙车牌左侧有一条竖黄色条纹，是区别于西班牙的快速特征。
  • 乌拉圭车牌白底蓝字、中央有国徽、底部写着 "Uruguay"，特征非常完整。
  • 印尼车牌黑底白字、模糊后呈现三段白色；马来西亚是两段白；且印尼摩托车有前车牌，其他东南亚国家多没有。
  • 俄罗斯车牌全白、没有欧盟蓝条；乌克兰车牌常带蓝黄国旗配色，看到蓝黄先想乌克兰。
  • 德国 vs 奥地利终极区分：看汽车挡风玻璃上的"神秘贴纸"——德国是环保标章，奥地利是定期保养标章，一秒区分这对双胞胎。

行车方向与道路标线

  • 左行国家约占世界三分之一人口：英国、日本、澳大利亚、印度、南非及东南亚多国；美洲和欧洲大陆基本右行。先看街景车所在车道就能砍掉半张地图。
  • 美洲多用黄色中线、欧洲多用白色中线（日本也用黄中线）；完全没有标线的破旧路面，多指向东欧、俄罗斯、中亚或非洲乡村。
  • 法国路侧线是独有的白色菱形虚线，看到菱形虚线直接锁法国。
  • 北欧标线可区分三国：瑞典路侧是小虚线、芬兰多为实线、挪威是实线与长虚线混合。
  • 乌拉圭：两条黄线夹一条白色虚线，加上三叉形电线杆，是标志性组合。
  • 南非道路外侧是黄色边线，看到外侧黄线先考虑南非。
  • 约旦道路黄外线 + 白中线；弯道箭头牌约旦是白底红箭头、以色列是黑底白箭头，箭头颜色可区分两国。

电线杆 / 路桩 / 街景车

  • 法国木质电线杆上一定有蓝色方形贴纸（偶有例外），是强特征。
  • 泰国电线杆杆身有孔洞、路桩是黑白相间的方尖碑形，杆桩组合锁定泰国。
  • 日本 vs 台湾 vs 韩国电线杆条纹：日本是黄黑条纹矩形、悬空离地；台湾同色斜条纹、贴着地面；韩国条纹更少、接近贴地——按"条纹是否触地"区分。
  • 乌克兰 / 罗马尼亚电线杆底部常刷白漆，看到白底杆先想这两国。
  • 路桩：西班牙是欧式黑白桩、黑色段内嵌亮黄矩形；冰岛路桩黄色；澳大利亚小红块、新西兰大红块。
  • 街景车 meta：日本 / 瑞士的车底盘很低；加纳的车有 4 根杆、其中一根缠黑胶带，肯尼亚同款车有黑色通气管；尼日利亚街景车后跟着警车；蒙古车顶有露营装备；巴拿马车有独特天线。
  • 哥斯达黎加没有街景车、只有人步行背着设备拍摄，看到步行视角先想哥斯达黎加。

易混国家对

  • 西班牙 vs 葡萄牙：看拼写——ñ 是西语，ã / ç / lh / nh 是葡语；"街"西语 calle、葡语 rua；葡萄牙房子多红/橙斜屋顶、路面有浅蓝色猫眼反光钉。
  • 阿根廷 vs 乌拉圭：乌拉圭看标线（三黄夹白虚线）+ 三叉电线杆 + 白底蓝字车牌；阿根廷看车牌黑点 + YPF 加油站。
  • 泰国 vs 越南 vs 柬埔寨：先看文字（泰文尾带圆圈、高棉文顶带钩）；柬埔寨在东南亚少见地靠右行，且 Angkor 啤酒广告牌、土路多；越南与韩国一样用红边黄底三角警告牌。
  • 波罗的海三国：立陶宛路灯柱上有特征性小梗；爱沙尼亚路侧白虚线、树比拉脱维亚/立陶宛多；"街"：爱沙尼亚语 tänav、拉脱维亚语 iela、立陶宛语 gatvė。
  • 巴尔干诸国：保加利亚用西里尔字母、街景常见埃菲尔铁塔状铁塔；罗马尼亚看 ț / ș；克罗地亚街景多为 2013 年拍摄；阿尔巴尼亚、黑山的天空常有拼接裂缝。

建筑 / 域名 / 其他

  • 德国：黄色邮筒、白底蓝字高速路牌、郊区独栋多无前院；法国：黄色村庄名牌、乡村路旁法国梧桐、巴黎多 Mansard 式黑瓦老虎窗屋顶。
  • 土耳其：停车牌写 "DUR"、路面多"盐胡椒"颗粒质感、城镇常见高宣礼塔和高方形公寓楼。
  • 约旦建筑多为浅色砂岩砖 + 平顶；秘鲁 / 玻利维亚民居多砖房 + 很平的屋顶；不丹房屋是平顶亚式风格。
  • 看到网址先看国家域名后缀（如瑞士 .ch），是零成本的国家线索。

南北半球判断

方法

  • 核心法则：太阳在南边 = 北半球，太阳在北边 = 南半球——所有半球判断的起点。
  • 影子法：用游戏内指南针面朝北，如果影子也指向北方（太阳在南）就是北半球；影子指南则是南半球。
  • 阴天无影子看卫星锅：锅口朝南 = 北半球、朝北 = 南半球（家用锅都对准赤道上空的同步卫星）；锅口朝天说明接近赤道。
  • 月相法：南半球看到的月亮盈亏方向与北半球镜像——月亮从左侧开始变圆的是南半球（北半球从右侧开始）。
  • 弦月法：把弦月两角连线延长到地平线，北半球大致指向南方、南半球指向北方，夜间无星时可定向。
  • 南十字星法：找到南十字星，沿其长轴延长约 4.5 倍，落点即为正南——南半球夜间标准定向法。
  • 组合技：南半球 + 左行 + 太阳在北，可把范围压到澳大利亚、新西兰、南非等少数国家；北半球 + 右行 + 太阳在南，则是欧美亚大陆的主流组合。

四个误区

  • 赤道附近（±10°内）太阳几乎在头顶，南北法基本失效——此时卫星锅朝天反而是"接近赤道"的更强信号。
  • 冬季拍摄的照片太阳高度角很低，用太阳位置判半球不可靠，不要过度依赖。
  • "松树 = 北半球、棕榈 = 南半球"是过度简化：南半球温带（新西兰、智利南部）也有大片针叶林，北半球热带到处是棕榈。植被只能做弱参考。
  • 看到"太阳在正头顶"就猜赤道是错的：除春秋分前后，太阳直射点只在南北回归线之间移动，大部分时间太阳并不在头顶。

语言 / 文字判断

先认体系，再认语言（不用读懂单词）

  • 看到文字先看体系：西里尔、阿拉伯、泰文、日文、韩文、希腊文每种都能一秒锁定大区域，拉丁字母内部再看变音符号。
  • 中日韩：日文假名线条弯曲、中文方正复杂、韩文呈圆润的方块状，笔触风格差异明显。
  • 泰文字符末尾带小圆圈；柬埔寨（高棉）文字符顶部带小钩——看到顶钩先想柬埔寨。
  • 印地文 / 孟加拉文字符顶部有一条横线；阿拉伯文是字母下方有一条基线——横线在上还是在下是关键区别。
  • 斯里兰卡僧伽罗文里有很多像字母 "c" 的变体，看到满屏 "c" 形字母就是斯里兰卡。
  • 希腊字母 α β γ δ 极易辨认，看到就是希腊或塞浦路斯。

同语系内拼写线索

  • 西语 vs 葡语：ñ 是西班牙语，ã / ç / lh / nh 是葡萄牙语。
  • 法语 vs 罗马尼亚语：ț / ș 是罗马尼亚语专属，看到直接锁罗马尼亚。
  • 西里尔三语：ї / є / ґ 只出现在乌克兰语，ы / ё 偏向俄语，ө / ү 是蒙古语——看到西里尔先找这几个特有字母。
  • 北欧：å / ä / ö 指向瑞典 / 芬兰，æ / ø 指向丹麦 / 挪威；芬兰语单词都很长（非印欧语系）。
  • 波兰语看 ą / ę / ł，德语看 ß 和 Straße，荷兰语 z / w 泛滥，匈牙利语"街"是 utca。
  • 意大利语单词多以元音结尾、常见 gg / cc 双写和 ì / à；土耳其语"街"是 sokak。
  • 印尼语字母 a 出现频率极高、单词多以 -kan 结尾；马来语相近，需结合车牌（三段白 vs 两段白）区分。
  • 停车牌关键词：墨西哥 / 危地马拉写 "ALTO"、土耳其写 "DUR"、哥伦比亚写 "PARE"——同为拉丁字母时靠固定词组区分西语国家内部。
  • 美国限速牌写 "SPEED LIMIT"、加拿大写 "MAXIMUM"——同为英语靠这组固定词区分美加。
